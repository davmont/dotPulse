# Puesta en marcha { #getting-started }

Esta sección le lleva de un servidor vacío a un sitio dotPulse en funcionamiento con su primer proyecto.

1. **[Requisitos](requirements.md)**: compruebe que su servidor tiene lo que dotPulse necesita: PHP 8.2 o posterior, MySQL o MariaDB, y un servidor web.
2. **[Instalación](install.md)**: ejecute el instalador web, inicie sesión por primera vez y proteja la instalación.
3. **[Actualización](upgrade.md)**: pase a una nueva versión de dotPulse, o traiga un sitio dotProject 2.x existente.
4. **[Primeros pasos](first-steps.md)**: la configuración, las personas y los módulos que debe preparar antes de que su equipo empiece a trabajar.

Cuando el sitio esté en marcha, la [Guía de uso](../user-guide/index.md) explica el trabajo diario, y [Administración](../administration/index.md) cubre en detalle cada ajuste, usuario, rol y módulo.

!!! tip "¿Viene de dotProject?"
    No necesita una instalación nueva. Lea [Actualización](upgrade.md): dotPulse actualiza en el sitio una base de datos de dotProject 2.x.

# dotPulse 3.3.3 Release Notes

**Release date:** 2026-11-23

dotPulse 3.3.3 is a **security release** for sites that deny users **single files** in their permissions. A file denied that way was still listed to the user, and could be downloaded when the user could see no other file. **Upgrade every installation of 3.3.2 or earlier that denies single files.** Sites that don't are not affected. See advisory [GHSA-p8w8-mj3x-c2cq](https://github.com/davmont/dotPulse/security/advisories/GHSA-p8w8-mj3x-c2cq).

It upgrades 3.3.2 in place, with no database changes.

---

## Security

- **Files denied one by one** (low). An administrator can deny a user, or a role, one file while the Files module stays open to them. The Files page and the Files tabs of projects and tasks ignored that deny and showed the file with its download link. The download itself was refused only while the user could see at least one other file: a user denied every file could download each one. Now the lists leave out the files denied to the user, and the download refuses any file the user may not see.

## Upgrading

1. **Back up** the database and the `files/` directory.
2. **Replace the code.** Keep `includes/config.php` and `files/`.
3. **Run the installer** (`install/` in a browser) to record the new version. There are no database changes. Then remove `install/` again or deny access to it.

From a version older than 3.3.2, read [the 3.3.2 release notes](v3.3.2.md) first.
